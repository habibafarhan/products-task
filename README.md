# Products Page

A responsive products page built with React, TypeScript, React Query, and Tailwind CSS.

## Features

- Fetch products from the DummyJSON API.
- Display product images, titles, prices, and ratings.
- Search products by name.
- Pagination with 10 products per page.
- View detailed information for each product.
- Loading, error, and empty states.
- Data caching using TanStack React Query.
- Responsive product cards.

## Technologies Used

- React
- TypeScript
- Vite
- TanStack React Query
- React Router
- Tailwind CSS
- DummyJSON API

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/habibafarhan/products-task.git
```

### 2. Navigate to the project folder

```bash
cd products-task
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

## API

Products API: https://dummyjson.com/products

Product Search API: https://dummyjson.com/products/search?q=phone
